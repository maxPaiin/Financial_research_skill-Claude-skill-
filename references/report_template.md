# Report Template

Implementation reference for `scripts/build_report.py`. Defines the structure, ordering, and styling of the final PDF output.

## 1. Tooling

`build_report.py` uses **ReportLab** (pure Python, available via `pip install reportlab --break-system-packages`). Bilingual text rendering requires a CJK font; the script auto-detects:
1. `Noto Sans CJK` if installed
2. `WenQuanYi Zen Hei` as fallback
3. Fails loudly with install instructions if neither is found

## 2. Document structure

Page size: A4. Margins: 18mm.

```
[Page 1]   Cover
           - Title: "Stock Fund Research Report / 股票型基金研究報告"
           - Subtitle: number of funds, generation timestamp
           - Generated by Claude — AI Analysis Only

[Page 2]   Disclaimer (front)
           - Verbatim from assets/disclaimer.md
           - Bordered box, both languages

[Page 3]   Executive summary / 執行摘要
           - 1-paragraph overview
           - Key numbers: # funds analyzed, # unique stocks, top-strategy CAGR
           - Top finding per strategy (one sentence each)

[Pages 4–N]  Fund profiles (1 page per fund)
           - Fund name, type, currency, reporting date
           - Top 10 holdings with weights
           - Fund-level scores: industry / growth / quality_value / 3 strategy composites
           - Top contributing & dragging holdings
           - Industry exposure bar chart

[Page N+1] Cross-fund overlap & concentration
           - Heatmap: stocks (rows) × funds (cols), cell = holding weight
           - Highlight cells where a stock appears in ≥ 3 funds
           - Industry concentration table per fund (flag > 30%)

[Page N+2] Per-stock score appendix
           - Sortable table: ticker | name | industry | industry_score | growth_score | quality_value | momentum | 3x strategy scores
           - Sorted by neutral total_score descending
           - Footnote for any unscored stocks (with reason)

[Page N+3 to N+5]  Strategy rankings (3 pages)
           - Page per strategy
           - Top 20 stocks ranked by that strategy's score
           - Top 5 funds ranked by aggregated score
           - Brief commentary on what drove each top pick

[Page N+6] Backtest results
           - Table: 3 strategies × {1y, 3y, 5y} × {CAGR, Sharpe, MDD, WinRate}
           - 3 equity curve charts (one per strategy, all 3 periods overlaid)
           - Data quality flags listed

[Page N+7] Forward investment view
           - 3 × 3 matrix table (strategies × horizons)
           - Each cell: 3 fund picks, expected return range, top 3 risks
           - Below table: "Triggers to revisit" per strategy

[Page N+8] Methodology notes
           - Verbatim limitations table from references/backtest_methodology.md §6
           - Data sources used (yfinance, FRED status)
           - Strategy weight schemes table
           - Skill version and timestamp

[Last page] Disclaimer (repeat)
            - Same as Page 2
```

## 3. Style guide

- **Headers**: 18pt bold for section titles, 14pt bold for subsections
- **Body**: 10pt sans-serif (Noto Sans CJK Regular)
- **Tables**: 9pt, alternating row shading (#f5f5f5)
- **Charts**: matplotlib via `matplotlib.use("Agg")`, saved as PNG and embedded
- **Color palette**:
  - Growth strategy: `#2E7D32` (green)
  - Conservative: `#1565C0` (blue)
  - Risk-avoidance: `#6A1B9A` (purple)
  - Warnings/flags: `#C62828` (red)
  - Neutral: `#424242` (dark grey)

## 4. Bilingual handling

Each section header is "English / 中文" on one line. Body paragraphs default to bilingual side-by-side using a 2-column block, OR English paragraph followed by Chinese paragraph if the content is too dense for side-by-side.

Tables use English column headers with Chinese in parentheses, e.g., `Ticker (代號) | Name (名稱) | Industry (行業)`.

## 5. ReportLab skeleton

```python
from reportlab.lib.pagesizes import A4
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Table, PageBreak, Image
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.lib import colors

# Register CJK font
pdfmetrics.registerFont(TTFont("CJK", "/usr/share/fonts/.../NotoSansCJK-Regular.ttc"))

doc = SimpleDocTemplate("output.pdf", pagesize=A4)
story = []

styles = getSampleStyleSheet()
styles.add(ParagraphStyle(name="CJK", fontName="CJK", fontSize=10, leading=14))

# ... build story
story.append(Paragraph("Stock Fund Research Report / 股票型基金研究報告", styles["Title"]))
story.append(PageBreak())
# ... etc
doc.build(story)
```

The full implementation is in `scripts/build_report.py`. It reads all JSON files from `/home/claude/work/` and assembles the document.

## 6. What MUST appear

Even in a degraded run (e.g., backtest skipped due to budget), the report must always include:
- Disclaimer (twice)
- Fund profiles with whatever scores were computed
- A clearly visible "Limitations of this report" section explaining what was skipped and why

A degraded report is OK; a misleading report is not.
